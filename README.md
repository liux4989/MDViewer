# Floating TOC for Obsidian

An interactive floating table of contents plugin for Obsidian that provides quick navigation through your documents.

## Features

- **Floating TOC Panel**: A sleek, draggable table of contents that appears on the left side of your editor
- **Smart Positioning**: Automatically positions itself for optimal viewing without obstructing your content
- **Active Heading Tracking**: Highlights the current section as you scroll through your document
- **Quick Navigation**: Click any heading to instantly jump to that section
- **Collapsible Sections**: Expand and collapse nested headings for better organization
- **Responsive Design**: Adapts to different screen sizes and layouts
- **Multi-level Support**: Supports all heading levels (H1-H6)

## Installation

### From Obsidian Community Plugins (Coming Soon)
1. Open Settings > Community plugins
2. Search for "Floating TOC"
3. Click Install, then Enable

### Manual Installation
1. Download the latest release from the [Releases page](https://github.com/liux4989/MDViewer/releases)
2. Extract the `floating-toc` folder to your vault's `.obsidian/plugins/` directory
3. Reload Obsidian
4. Open Settings > Community plugins and enable "Floating TOC"

## Usage

Once enabled, the Floating TOC will automatically appear when you open a markdown file with headings. You can:

- **Drag** the TOC panel to reposition it
- **Click** on any heading to navigate to that section
- **Expand/Collapse** nested headings using the arrow indicators
- **Hide/Show** the TOC using the command palette

## Commands

- `Toggle Floating TOC`: Show or hide the table of contents panel
- `Refresh TOC`: Manually refresh the table of contents

## Settings

Configure the plugin behavior in Settings > Plugin Options > Floating TOC:

- **Auto-hide**: Automatically hide TOC when not in use
- **Position**: Default position of the TOC panel
- **Opacity**: Adjust the transparency of the TOC panel
- **Width**: Set the preferred width of the TOC panel

## Compatibility

- Requires Obsidian v0.15.0 or higher
- Works on desktop and mobile devices
