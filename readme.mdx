# Features
- display with two mode: compact and detailed
- display content : only h1-h2-h3 3 levels
- respond to user's scroll : compat mode hightlight the current heading , if current mode's is detailed is hightlight  the current heading and since the limit  length of detail window, the window is also scroll to the current heading
- response to user's hover: compat mode will convert to detail mode, if the user pointer leave, the mode will convert to compat mode
- response to user's hover on specific heading in detail mode: hightlight the headings
- response to user's click on specific heading in detail mode: scroll the current article to the heading

# Style
- obsidian - built in style
- compat mode: tree view with different line length to represent the level of the heading
